# sql-dashboard-project- Zomato analysis project 
Analyzed restaurant data covering cities, countries, ratings, cuisines, pricing, table bookings, online delivery, and opening trends.
Built Country Mapping and Calendar tables and used SQL JOINs, aggregations, CASE statements, date functions, DISTINCT, and window functions.
Developed KPIs for Total Restaurants, Average Rating, Total Cities, Total Countries, Average Cost, Table Booking %, and Online Delivery %.
Performed city/country, rating, price-bucket, cuisine, and restaurant-opening trend analysis and prepared results for dashboard visualization.etc
